# 🌍 Language Translation Tool

A modern and responsive Language Translation Tool built using **Python**, **Flask**, and **Deep Translator**. It allows users to translate text between multiple languages through a clean and colorful web interface.

---

## ✨ Features

- 🌐 Translate text into multiple languages
- 🔍 Automatic language detection
- 🎨 Beautiful and responsive UI
- ⚡ Fast translation using Deep Translator
- 💻 Built with Flask and Python
- 📱 Works on desktop and mobile devices

---

## 🛠 Tech Stack

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- Deep Translator

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/Ankita0240/Language-Translation-Tool.git
```

Move into the project folder:

```bash
cd Language-Translation-Tool
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate the virtual environment:

### Windows

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```
